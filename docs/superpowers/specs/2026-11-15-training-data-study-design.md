# Which Training Data Makes Deep Hedging Work on Real Hong Kong Stocks? — Design

Date: 2026-11-15. Approach chosen by the author in chat: "train approach 3" (compare training data).
Status: design for approval; build starts 19:00 HKT.

## Intent and why
Turn the project into a publishable empirical study. The current result trains only on
simulation. A paper needs to answer the question practitioners and reviewers ask next: *would
real data, or a more realistic simulator, train a better hedger, and is a neural network even
needed?* Mikkilä & Kanniainen (QF 2023) trained on real S&P 500 option data; Ruf & Wang (JBES 2022)
showed a linear regression can match a neural network and that sloppy splits overstate NNs.
Hong Kong single stocks with HK costs are not covered. This study compares training data on one
fixed, untouched real test set.

## Research question and pre-registered hypotheses
**RQ:** On real Hang Seng Tech stocks (2016–2026), which training data gives the deep hedger the
lowest tail risk (CVaR₉₅ of hedging P&L) after transaction costs?

Fixed before any result is seen (primary cost = 15 bps per side):
- **H1:** Hedgers trained on real-informed data (A2 GARCH-t, A3 bootstrap, A4 real, A5 fine-tune)
  have lower CVaR₉₅ than the GBM-trained hedger (A1).
- **H2:** The best deep hedger beats the linear benchmark (L).
- **H3:** The deep hedger's gain over BS delta grows with cost (as in the current study).
All arms and all costs are reported, whichever way they come out.

## Test protocol (identical for every arm)
- **Task:** sell a 1-month (21 trading days) ATM call, hedge daily with the stock, premium and
  delta from trailing 63-day vol — exactly the current real study.
- **Test set:** the same 2,650 non-overlapping windows starting 2016-01-01 → 2026 (continuity with
  published results).
- **Walk-forward:** for each test year Y = 2016…2026, a model may use only prices dated before
  Y-01-01; training windows must *end* before Y-01-01. 11 folds, results pooled over all test years.
- **Costs:** 0, 5, 10, 15, 25, 50 bps per side; primary 15 bps.
- **Seeds:** 3 training seeds per (arm, fold, cost); CVaR per seed, then averaged.
- **Statistics:** paired month-clustered bootstrap (as now) of each arm vs BS delta and vs A1;
  CVaR differences with 95% CI. Note multiple comparisons in the paper (6 arms × 6 costs).

## Training arms
All synthetic paths are 84 days: 63 warm-up days to compute the trader's trailing vol the same
way as on real data, then the 21-day hedge. So every arm trains with realistic vol *estimation*
error, not a known vol.

| Arm | Training data (from data before Y only) |
|---|---|
| A0 | GBM, trader knows the true vol — the current published method (continuity) |
| A1 | GBM with vols drawn from history, trader *estimates* vol (63-day trailing) |
| A2 | GARCH(1,1) with Student-t shocks, fitted per stock by maximum likelihood |
| A3 | Stationary block bootstrap of each stock's real daily returns (mean block 10 days) |
| A4 | Real only: overlapping real windows (one starting every trading day per stock) |
| A5 | Pre-train on A1, then fine-tune on A4's real windows |

**Benchmarks (no neural net):** BS delta, delta + no-trade band, no hedge, and **L — linear
correction**: holding = δ + a + b·δ + c·δ², with (a, b, c) fitted by least squares to minimise the
variance of terminal hedging P&L on real pre-Y windows (Hull–White minimum-variance-delta form;
Ruf & Wang's benchmark idea).

## Fixed settings (chosen now, never tuned on 2016+)
Network 4-32-32-1 (unchanged); Adam lr 0.01, 200 epochs, batch 256; 6,000 training paths per fold
for synthetic arms; A4 uses all available real windows; A5 fine-tune 50 epochs at lr 0.002.
Bootstrap mean block length 10 days. GARCH fitted only for stocks with ≥ 500 pre-Y returns.

## Extra analyses
1. **Realism vs performance:** for each generator and fold, excess kurtosis, autocorrelation of
   |returns| (lags 1–10) and Hill tail index vs the real pre-Y data; plotted against its CVaR.
2. **Stability over time:** each arm's CVaR gap to BS delta by test year.
3. **Data quantity:** A4's result against how many real training windows each fold had.

## Outputs
`results/training_data/` (tables, CSV), `figures/training_data/` (≈6 charts), `configs/training_data.json`,
`python -m deephedge.experiments.run_training_data`, and `paper/outline.md` updated with the
findings. Everything regenerated by `scripts/run_all.sh`.

## Goals, non-goals, anti-goals
- **Goals:** a fair, reproducible comparison on one untouched real test set; honest reporting.
- **Non-goals:** reinforcement learning; real option prices / implied vol (not freely available
  for HK); new markets; architecture search.
- **Anti-goals:** any test-year information in training (fails the study even if numbers look
  good); reporting only the winning arm; tuning anything on 2016+.

## Constraints and known limitations
- Only 9 of 29 stocks were listed before 2016, so early folds (2016–2018) train on few stocks;
  report training-set size per fold.
- Survivorship (today's index members), trailing vol instead of implied vol, single-stock hedge.
- Compute: ~990 trainings × ~5 s on 2 cores ≈ 45–90 min; parallelised across arms/folds.

## Calls I made (author can change)
- A0 kept for continuity; A5 pre-trains on A1 (not the best synthetic arm, which would need test
  information to pick).
- Linear benchmark fitted without costs (least squares can't see them), stated as such.
- Fixed hyperparameters from the existing study, no validation tuning.
